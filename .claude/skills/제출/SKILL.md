# /제출

1. 화면에서 저장하지 않은 변경이 있으면 먼저 화면에서 저장하라고 알려 준다.
2. `uv run app.py submit`을 실행한다. 실행 기록을 점검하고 prompts/·runs/를 커밋·푸시한 뒤 PR을 연다.
3. 출력에 나온 경고를 그대로 전한다.
   - ③ 프롬프트가 v9.0.0과 같으면 패널티 대상이다.
   - 입력·출력 형식 영역이 바뀌었으면 공식 평가에서 생성이 실패할 수 있다.
4. PR 링크를 전한다. gh가 없거나 로그인돼 있지 않으면 출력된 링크를 브라우저에서 열어 PR을 만들라고 안내한다(base: main, compare: 개인 브랜치).
5. 마감 전까지 다시 고치고 `/제출`하면 같은 PR에 커밋이 쌓이고, 마감 시점의 마지막 커밋이 제출본이라고 알려 준다. PR은 머지하지 않는다.
