# /제출

1. 화면에서 저장하지 않은 변경이 있으면 먼저 화면에서 저장하라고 알려 준다.
2. `uv run app.py submit`을 실행한다. 실행 기록을 점검하고 prompts/·runs/를 커밋·푸시한 뒤 PR을 연다.
3. 제출이 막히면 이유를 그대로 전한다. ③이 v9.0.0과 같거나 바뀐 분량이 5% 미만이면 제출할 수 없다(공백·빈 줄 차이는 세지 않는다). 기준을 넘기려고 뜻 없는 문장을 덧붙이자고 제안하지 않는다. 프롬프트를 실제로 개선할 방향을 함께 찾는다.
4. 출력에 나온 경고를 그대로 전한다. 입력·출력 형식 영역이 바뀌었으면 공식 평가에서 생성이 실패할 수 있다.
5. PR 링크를 전한다. gh가 없거나 로그인돼 있지 않으면 출력된 링크를 브라우저에서 열어 PR을 만들라고 안내한다(base: main, compare: 개인 브랜치).
6. 마감 전까지 다시 고치고 `/제출`하면 같은 PR에 커밋이 쌓이고, 마감 시점의 마지막 커밋이 제출본이라고 알려 준다. PR은 머지하지 않는다.
