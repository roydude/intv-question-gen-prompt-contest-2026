# /생성

1. 인자가 없으면 한 사이클(공통 케이스 10개, 질문 20개)을 만든다. 케이스를 주면 그 케이스만 만든다(케이스당 질문 2개). 케이스만 고르면 평가 점수는 계산하지 않는다.
2. 실행 전에 `uv run app.py status`로 남은 질문을 확인하고, 이번에 쓸 질문 수와 함께 알려 준 뒤 진행할지 한 번 묻는다.
3. `uv run app.py generate [--cases P01,P03] [--model ...] [--effort ...]`를 실행한다. 몇 분 걸릴 수 있으니 타임아웃을 10분으로 넉넉히 둔다.
4. 결과를 짧게 정리한다. 평가 점수(또는 질문 점수 평균), J1~J4, 많이 걸린 실패 유형, 규칙 진단 위반.
5. 점수가 낮은 질문 2~3개를 결과 파일(runs/<실행 ID>.json)에서 찾아 근거(reasons)를 보여 주고, 프롬프트의 어느 규칙을 손보면 좋을지 제안한다. 골든셋의 참고 질문을 프롬프트에 옮겨 적자고 제안하지 않는다.
